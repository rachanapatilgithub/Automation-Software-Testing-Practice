# Automation Software Testing - Practice

Daily Selenium (and early Playwright) automation practice and homework, done while
training with Kiran Academy. Each folder is a separate day's task - a small, focused
Java/Maven project exploring one automation concept at a time, not a single unified
framework.

## Topics covered

- **Locators & element handling** - August05Locators, August11Locators
- **Alerts & pop-ups** - August01PopUpAlert, August03PopAlert
- **Window handling** - August04WindowHandling
- **Action Classes** - mouse hover, drag-and-drop, right-click, keyboard actions
  (August17_ActionClass, August18_ActionClasses, Aug17_18_ActionClass_Updated,
  August19_ActionClass)
- **JavaScript Executor** - August20_JavascriptExecutor
- **Form field practice** - July29HomeWorkTask2, July30SelfPracticeFormField
- **RedBus homework tasks** - end-to-end search flows on redBus.in
  (August12_Task_RedBus, Aug13_RedBusTask_2, August15_HomeWorkTask)
- **Playwright intro** - August21_playwright, first look at Playwright right after
  learning Selenium

## Tech stack

Java, Selenium WebDriver, Maven, Eclipse IDE - each dated folder is its own small
Maven project.

## Note

This is homework/practice, not a polished framework - each folder stands alone and
some are rougher than others. For complete, portfolio-grade automation frameworks,
see [CubeCart-Selenium-Automation-Framework-Project](https://github.com/rachanapatilgithub/CubeCart-Selenium-Automation-Framework-Project)
and [CubeCart-Playwright-Automation-Framework-Project](https://github.com/rachanapatilgithub/CubeCart-Playwright-Automation-Framework-Project).
