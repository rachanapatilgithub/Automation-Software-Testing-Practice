# Automation - Software Testing Practice

Daily hands-on practice while learning Selenium and Playwright - one dated folder per topic/session, in the order they were learned.

This is a practice log, not a single project - each folder is a small, self-contained Maven exercise (Alerts, Window Handling, Locators, Action Class, JavaScript Executor, an early look at Playwright, plus a couple of take-home tasks). The polished, interview-ready work is in dedicated repos like [CubeCart-Selenium-Automation-Framework-Project](https://github.com/rachanapatilgithub/CubeCart-Selenium-Automation-Framework-Project) and [RedBusTripPlanner-Selenium-Automation-Project](https://github.com/rachanapatilgithub/RedBusTripPlanner-Selenium-Automation-Project) - this repo is the practice trail that led there.

## Topics covered, roughly in order
- Locators, form fields, dropdowns
- Alerts and pop-ups
- Window/tab handling
- Action Class (mouse/keyboard actions)
- JavaScript Executor
- A first look at Playwright
- Two small take-home tasks (RedBus site practice)
- Excel sheet (Apache POI) + properties file driven Login/Register/Add User, plain classwork and a reusable-utility-class version side by side

## Tech
Java, Selenium WebDriver, Maven
